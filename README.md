# 📂 Projeto: Rocklov

🔗 Repositório público: [viniciuscarneironascimento/rocklov](https://github.com/viniciuscarneironascimento/rocklov)

---

## 📝 Descrição

Repositório do portfólio referente ao curso de **Automação de Testes com Ruby, Cucumber, Capybara e Selenium WebDriver**, ministrado pelo instrutor **Fernando Papito (QA Ninja)**.

Projeto focado em **automação de testes funcionais**, desenvolvido com abordagem **BDD**.  
Os testes foram escritos em **Ruby**, utilizando:

- **Cucumber** para definição dos cenários em Gherkin;
- **Capybara** para simular interações com a interface web;
- **Selenium WebDriver** para controle do navegador;
- **RSpec** para asserções e validações.

---

## 🚀 Resultados Alcançados

- ✅ Montagem completa da arquitetura de um projeto de testes automatizados, com foco em testes **web** e de **API**.

### 🧪 Testes Web
- Utilização de **Cucumber** para escrita de cenários em Gherkin (seguindo os princípios de BDD);
- **Capybara** e **Selenium WebDriver** para simulação da navegação e interação do usuário;
- **RSpec** para validações dos comportamentos esperados.

### 🔌 Testes de API
- **HTTParty** para requisições HTTP;
- **Rack::Test** para testes de APIs locais e integração com serviços;
- **Cucumber-Rails** para integração com aplicações Ruby on Rails;
- **RSpec** para validação das respostas;
- **MongoDB** para manipulação e validação de dados no banco, conforme a necessidade dos testes.

### 🛠️ Outras Tecnologias e Práticas
- **Faker** para geração de dados dinâmicos e realistas (ex: nomes, e-mails, CPF);
- **Allure** para geração de relatórios de testes, utilizando a versão `allure-cucumber 2.14.1`.
